## ✏️ Где менять контент

### Тексты на главной странице

Откройте `index.html` и найдите комментарии:

```html
<!-- COMPANY -->
<!-- HERO -->
<!-- PROCESS -->
<!-- DOCUMENTS -->
<!-- CONTACT FORM -->
<!-- CONTACTS -->
<!-- FOOTER -->
```

Все тексты находятся прямо в HTML-коде между этими комментариями.

**Пример замены заголовка:**
```html
<!-- Было -->
<h1 class="hero-title">Внедряем ИИ-агентов<br>в ваши процессы продаж</h1>

<!-- Стало -->
<h1 class="hero-title">Ваш новый заголовок здесь</h1>
```

### Контакты

В `index.html` найдите секцию `<!-- CONTACTS -->`:

```html
<a href="tel:+7XXXXXXXXXX" class="contact-value">+7 XXX XXX-XX-XX</a>
<a href="https://t.me/telegram" class="contact-value">@telegram</a>
<a href="mailto:hello@i-pro.tech" class="contact-value">hello@i-pro.tech</a>
```

Замените placeholder на реальные контакты.

**Не забудьте обновить контакты также в:**
- `index.html` (footer)
- `privacy.html` (footer и раздел контактов)

### PDF-файлы

Положите файлы в папку `/assets/`:

1. **Презентация:** `presentation.pdf`
2. **Пример отчёта:** `report-example.pdf`

Ссылки уже настроены в `index.html` в секции `<!-- DOCUMENTS -->`.

### Политика конфиденциальности

Откройте `privacy.html` и замените текст-placeholder на юридически корректный текст от вашего юриста.

Найдите комментарий:
```html
<!-- LEGAL PLACEHOLDER CONTENT -->
<!-- Replace with actual legal text from your lawyer -->
```

### Яндекс.Метрика

Откройте `index.html`, найдите секцию в `<head>`:

```html
<!-- YANDEX METRICA -->
<!-- <script>
...
ym(YM_COUNTER_ID,"init",{...});
</script> -->
<!-- END YANDEX METRICA -->
```

1. Раскомментируйте код (удалите `<!--` и `-->`)
2. Замените `YM_COUNTER_ID` на номер вашего счётчика

## 🌐 Как запустить локально

### Вариант 1: Просто открыть в браузере

Дважды кликните по файлу `index.html` — сайт откроется в браузере.

⚠️ **Важно:** При таком способе могут не работать некоторые функции (например, плавная прокрутка к якорям).

### Вариант 2: Локальный сервер (рекомендуется)

Если у вас установлен Python:

```bash
cd /workspace
python3 -m http.server 8000
```

Откройте в браузере: `http://localhost:8000`

Если у вас установлен Node.js:

```bash
npx serve /workspace
```

### Вариант 3: Расширение Live Server (для разработчиков)

Установите расширение **Live Server** в VS Code, откройте проект и нажмите "Go Live".

## 📤 Как загрузить на хостинг (ISPmanager)

### Шаг 1: Подготовка файлов

Убедитесь, что у вас есть все файлы:
- `index.html`
- `privacy.html`
- `css/styles.css`
- `js/main.js`
- `assets/favicon.svg`
- `assets/presentation.pdf` (если есть)
- `assets/report-example.pdf` (если есть)

### Шаг 2: Загрузка через ISPmanager

1. Зайдите в панель ISPmanager
2. Откройте **Менеджер файлов**
3. Перейдите в корневую папку вашего домена (обычно `/var/www/i-pro.tech/www` или类似)
4. Загрузите все файлы из `/workspace/` в эту папку

**Важно:** Сохраните структуру папок:
```
/www/
├── index.html
├── privacy.html
├── css/
│   └── styles.css
├── js/
│   └── main.js
└── assets/
    ├── favicon.svg
    ├── presentation.pdf
    └── report-example.pdf
```

### Шаг 3: Проверка

Откройте `https://i-pro.tech` в браузере и проверьте:
- Все ли тексты отображаются
- Работают ли ссылки
- Корректно ли выглядит на мобильном

## 📧 Настройка формы обратной связи

Сейчас форма подготовлена для отправки данных на `/send.php`.

### Что нужно сделать backend-разработчику:

1. Создать файл `send.php` в корне сайта
2. Настроить отправку через SMTP Яндекс 360
3. Обработать POST-запрос с JSON-данными

**Данные приходят в формате:**
```json
{
    "name": "Имя клиента",
    "company": "Название компании",
    "phone": "79991234567",
    "consent": "on"
}
```

### ⚠️ Важно

- **Никогда не храните SMTP-credentials во frontend-файлах**
- Все секретные данные только в `send.php`
- Используйте environment variables или отдельный конфиг-файл вне доступа из веба

## 🎨 Дизайн-система

Если захотите изменить цвета или шрифты, откройте `css/styles.css` и найдите секцию `:root`:

```css
:root {
    --color-primary: #0066CC;        /* Основной цвет бренда */
    --color-bg-primary: #FAFAFA;     /* Фон страницы */
    /* ... другие переменные ... */
}
```

Изменяя эти переменные, вы измените стиль всего сайта.

**Полная документация:** `/design/DESIGN_SYSTEM.md`

## 🆘 Если что-то пошло не так

### Сайт выглядит «сломанным» после загрузки на хостинг

Проверьте пути к файлам. Убедитесь, что структура папок сохранена:
- `css/styles.css`
- `js/main.js`

### Форма не отправляет заявки

1. Проверьте, существует ли `send.php`
2. Проверьте логи ошибок PHP
3. Убедитесь, что SMTP-настройки корректны

### Мобильное меню не открывается

Убедитесь, что `js/main.js` загружается правильно. Проверьте консоль браузера на ошибки.
